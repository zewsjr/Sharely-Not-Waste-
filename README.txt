Sharely Not Waste! - GitHub Pages upload files

1. Unzip this archive on your computer.
2. Go to https://github.com/new and make a public repository called sharely-not-waste.
3. On its Code page, select Add file > Upload files.
4. Upload ONLY index.html (README.txt is optional). Do not upload the ZIP archive.
5. Click Commit changes.
6. Repository Settings > Pages > Build and deployment:
      Source: Deploy from a branch
      Branch: main
      Folder: / (root)
   Click Save.
7. Wait for GitHub Pages deployment, then open:
   https://YOUR-GITHUB-USERNAME.github.io/sharely-not-waste/

Notes:
- The standalone index.html includes embedded images. You do not need an assets folder.
- The external YouTube video and NEA source links require internet.
- Visual imagery is illustrative; do not present it as photographic evidence of your group's actual work.
- Publishing a public repo makes its website source publicly viewable.
